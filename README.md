## 💻 Como rodar os projetos localmente

Como este é um monorepo (vários projetos em um só lugar), você deve entrar na pasta do projeto específico que deseja rodar.

1. Clone o repositório:
```bash
git clone https://github.com/EduKaique/jornada-react.git
```

2. Entre na pasta do projeto desejado (exemplo):
```bash
cd 02-contador
```

2. Instale as dependências e rode o projeto:
```bash
npm install
npm run dev
# ou
yarn install
yarn dev
```
